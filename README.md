# Pantry Planner

A single-user, offline-first pantry ledger and meal planner. See `SPEC.md` for the full build
specification this project follows.

Zero-cost, no accounts, no backend. All data lives in IndexedDB on your device.

## Status

**Phase 1 — Foundation.** Dexie schema (six tables), PWA shell, GitHub Pages deploy pipeline.
No pantry or recipe UI yet — those land in Phase 2 and Phase 3. See `SPEC.md` §9 for the full
build order.

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm run test
```

## Build

```bash
npm run build
npm run preview   # serve the production build locally
```

The build is a static bundle configured for GitHub Pages under `/pantry-planner/`
(see `base` in `vite.config.ts`). Pushing to `main` runs `.github/workflows/deploy.yml`,
which tests, builds, and publishes to GitHub Pages.

## Installing as a PWA

Open the deployed URL (or a `npm run preview` build) on a phone and use "Add to Home Screen"
(iOS Safari) or the install prompt (Android Chrome). The app works fully offline once installed.

## Icons

Placeholder icons live in `public/icons/`, generated by `npm run icons`
(`scripts/generate-icons.mjs`). Replace them with real artwork whenever — regenerating just
means rerunning that script with new colors/inputs.
